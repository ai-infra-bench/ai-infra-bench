## Frozen contract

- Surface problem: adaptive streaming leaks MiniMax reasoning into `content`; enabled streaming starts in reasoning but fails to transition from a split-token closing marker into structured tool parsing.
- Instruction start: user-facing request and observable streaming/non-streaming comparison (A/B).
- Deterministic boundary: model execution only. The substitute emits fixed valid tokenizer IDs and decoded text; tokenizer loading, chat-template rendering, request validation, serving logic, parser registration, reasoning parsing, tool parsing, and SSE serialization are real.
- Desired result: adaptive and enabled streaming emit reasoning only in `reasoning`, hide marker text, and emit the same structured function call as non-streaming.
- Regression boundary: disabled mode, atomic markers, non-streaming parsing, plain streaming text, ordinary marker-like suffixes, varied tool schemas, and request-local parser state.
- Negative boundary: incomplete strings that merely resemble marker prefixes remain visible content rather than being swallowed or treated as completed markers.
- Scope: CPU reduced reproduction combining PR 45718 with the adaptive/prompt-initialization failures in issues 46042 and 50549. Model execution is the only substituted boundary; continuation, Responses, batch, and structured-output paths remain out of scope.
