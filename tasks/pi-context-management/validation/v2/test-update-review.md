# 根据真实模型结果更新测试

题面和参考实现未修改。本次修改测试和观测代码，不把模型多切换直接变成 benchmark 的扣分条件。

## 确定性执行回归

新增 repeated_unchanged：保留带有“下一步调用 new_context”的同一份笔记，连续请求十一轮切换。逐轮检查笔记原文与用户/系统指令仍在、旧助手/工具消息退出；最后用早先获得的 ID 读取完整原始证据，再正常执行工具。测试验证扩展的执行机制，不声称能阻止模型重复决策。

新增 repeat-history-loss 错误对照：前三次切换正常，之后无法读取旧窗口。它通过其余十一项，只在新增测试中因原来有效的 history_read ID 不再可读而失败。错误工具文本为 Record not found；评分脚本随后的 JSONDecodeError 是这一工具失败的下游表现，并非依赖或初始化故障。

正式 Harbor/Docker：参考实现与独立存储替代实现均 12/12、reward 1；Base 与七种错误对照均 reward 0，十次运行无 Harbor 异常。执行文件哈希、镜像及逐项结果见 test-update-results.json，原始请求和事件见 artifacts/pi-context-test-update-20260914/remote。

## 真实行为测试

将临时脚本整理为 validation/live 下可指定 repo/model/output 的独立入口。模型仍真实生成全部工具调用、参数、笔记和查询；观察器不替模型选择下一步。

新增行为效率统计：成功切换调用、场景参照下的多余切换、没有新证据的切换、同窗口重复历史读取/查询、错误工具调用、报告的 token 消耗。统计按 phase + call ID 去重；网络重试不计入工具次数；跨窗口必要的历史恢复不按同窗口重复读取计算。这些指标不影响 deterministic reward。

新增完成性判定：每阶段最后一条助手消息必须正常 stop 且包含最终文本。不能凭 JSON 模式进程退出码 0 或成功提交报告宣布完整完成。未完成当前阶段时，不自动推进下一阶段。

新增阶段所属进程监控：只因声明的时间或请求预算停止当前阶段句柄；不因发现重复切换自动终止，且不能在下一阶段启动后误杀它。十三个单测覆盖去重、错误终态、流内错误计数、跨阶段预算及停止竞态。

旧轨迹只读回放：GPT-6 多余切换 0，GPT-5.6 多余切换 8。原始第二阶段中断与恢复后的完成分别记录，恢复不作为新的独立样本。

新入口还实际运行了 GPT-6 一次：两个阶段完整结束，21 次模型请求，3 次切换、额外切换 0，原始字段和历史引用正确。三次阶段一的额外搜索用于保存来源引用，测试接受这种合法差异，没有限定固定工具序列。出现的 6 次 HTTP 429 退避后恢复，单独记录为基础设施事件。

第一次入口准备因解析虚拟环境 Python 的符号链接而误用系统解释器，网关缺 fastapi，在任何模型调用前失败；修复为保留虚拟环境路径后重新启动。该准备失败保留在 live-smoke，不混入模型成绩；真实执行证据位于 live-smoke-fixed。
